登壇: 藤野洋右 氏(任天堂 UI/UX デザイナー。Nintendo みまもり Switch、Nintendo Switch Online、ニンテンドーeショップなどを担当)

## 背景
- 自身の子ども時代、ゲーム機の AC アダプタを隠された経験。**買ってくれた母と、隠した人が同じ**というもどかしさ
- 親が子どもの状況を「分からない・知れない」ことが、**一方的な制限**の原因になる
- コンセプト: **子どもに安心して渡せるゲーム機**

## みまもり Switch とは
- 保護者がスマホアプリで、子どものプレイ時間の制限・機能制限を設定
- 子どものプレイ記録をスマホで見られる

## UI の3つの工夫
### 1. 一瞬で把握できるように
- 子どもが最近遊んだゲームのアイコンを、**目に飛び込む**ように配置
- ゲームに詳しくない保護者でも、キャラクターを見て**会話のきっかけ**に
- 日付ではなく**曜日**で表示 → 「◯曜日は塾じゃないの?」のような自然な会話が生まれる

### 2. 「良い・悪い」を押し付けない
- 検討段階にあった「よかった」「残念」マークを**削除**(保護者に先入観を与えないため)
- グラフも採用しなかった(時間は分かるが「何を遊んだか」が抜け落ちる)

### 3. アラームと中断モード
- アラーム: 設定時間に通知 / 中断モード: 強制的にスリープ
- 中断モードの設定は**あえて奥に**配置 → まず親子で話し合うことを促す
- 保護者の「すぐ止めたい」という欲求には反するが、**親子の関係**を優先した設計

## 検証方法
- 利用者の可視化・行動分析
- 家族それぞれの一日のタイムラインを見える化
- サービスデザインの考え方を重ねる(アプリ単体ではなく家庭の中の体験として)

## 成果
- App Store 4.4、Google Play 4.5 の評価、世界66か国で同時リリース

## 最終的なコンセプト
**「親子にとっての安心とは、笑顔でいられること」**。体験の軸はアプリの中ではなく、アプリの外で家族が笑顔になること。

## Web 制作への翻訳
| みまもりの工夫 | Web での実践 |
| --- | --- |
| 関係する人全員を考える | 利用者だけでなく、管理者・受け取る人・家族・同僚などステークホルダーを書き出す |
| 一瞬で把握 | ダッシュボードは「数字」より「次の行動・会話のきっかけ」になる情報を上に |
| 表示の単位を工夫(曜日) | ユーザーの生活・業務のリズムに合わせた表示(「今週」「営業日」など) |
| 評価を押し付けない | 「悪い」「失敗」ラベルを安易に付けない。事実を中立に見せる |
| あえて奥に置く | 強い操作(削除・退会・強制停止)は、手前に代替手段を置いて慎重に |
| アプリの外の体験 | 通知・メール・印刷・人との会話など、画面の外でどう役立つかまで考える |
