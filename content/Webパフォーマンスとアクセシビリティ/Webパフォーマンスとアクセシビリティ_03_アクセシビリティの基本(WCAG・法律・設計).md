## アクセシビリティとは
**障害の有無・年齢・環境にかかわらず、誰でも情報やサービスを利用できること**。略して a11y(a と y の間に11文字)。
| 使う人の例 | 使い方 |
| --- | --- |
| 目が見えない・見えにくい | **スクリーンリーダー**(読み上げ)、拡大、ハイコントラスト |
| 色の見え方が違う | 色だけで区別されると分からない |
| 手が不自由 | **キーボードだけ**、音声入力、スイッチ |
| 耳が聞こえない | 動画の字幕・書き起こし |
| 認知・学習の特性 | わかりやすい言葉、一貫した操作、時間制限なし |
| 一時的・状況的な制約 | けがで片手、屋外で画面が見えにくい、騒がしい場所 |
- 高齢化で利用者は増え続けている。**アクセシブルなサイトは誰にとっても使いやすい**(字幕・キーボード操作・わかりやすい文章)

## 法律と基準(2026年10月時点)
| 名前 | 内容 |
| --- | --- |
| **障害者差別解消法**(日本) | **2024年4月から民間事業者も「合理的配慮の提供」が義務**。Web についても、環境の整備(事前の改善)が努力義務 |
| **JIS X 8341-3** | 日本の Web アクセシビリティの規格。WCAG と同じ内容 |
| **WCAG 2.2**(W3C) | 世界の基準。2023年10月勧告。**レベル AA が一般的な目標** |
| 欧州アクセシビリティ法(EAA) | 2025年6月から EU で多くのデジタルサービスに適用 |
- 公共機関・大企業では、発注の条件や公開の方針(**アクセシビリティ方針・試験結果の公開**)を求められることが多い
- デジタル庁の「ウェブアクセシビリティ導入ガイドブック」が日本語でわかりやすい

## WCAG の4原則(POUR)
| 原則 | 意味 | 例 |
| --- | --- | --- |
| **知覚可能**(Perceivable) | 情報を受け取れる | 画像の代替テキスト、字幕、十分なコントラスト、色だけに頼らない |
| **操作可能**(Operable) | 操作できる | キーボードで操作、十分な時間、点滅しない、フォーカスが見える、押しやすい大きさ |
| **理解可能**(Understandable) | 理解できる | わかりやすい文章、予想どおりの動き、入力エラーの説明 |
| **堅牢**(Robust) | いろいろな支援技術で使える | 正しい HTML、名前・役割・状態が伝わる |
- 達成基準には A / AA / AAA のレベルがある。**A と AA を満たす**のが一般的な目標

## 特に大事な達成基準(AA までの抜粋)
| 項目 | 基準 |
| --- | --- |
| 代替テキスト | 意味のある画像に `alt`。飾りの画像は `alt=""` |
| **コントラスト** | 文字 **4.5:1**、大きな文字(18pt / 14pt 太字以上)**3:1**、ボタンの枠・アイコンなど **3:1** |
| 色だけに頼らない | エラーを赤字だけで示さない(アイコン・文章も) |
| **キーボード** | 全部の機能をキーボードで。操作できなくなる罠(抜け出せない)を作らない |
| **フォーカスが見える** | どこにいるか見える。固定ヘッダーなどで隠れない(2.2 で追加) |
| ターゲットのサイズ | 押す場所は**最低 24×24px**(2.2 で追加。44px 以上が望ましい) |
| 拡大 | 200% に拡大しても読める・使える。幅 320px で横スクロールしない |
| ページのタイトル・見出し・言語 | `<title>`、見出しの階層、`<html lang="ja">` |
| フォームのラベルとエラー | ラベル、何が間違いか・どう直すかの説明 |
| 動き | 自動で動くものは止められる。3回以上点滅しない |
| ドラッグに代わる操作 | ドラッグだけでなくクリックでもできる(2.2 で追加) |
| 認証 | パズル・記憶に頼る認証だけにしない。パスワードの貼り付けを禁止しない(2.2 で追加) |

## 設計の段階で考えること
- デザインの段階でコントラスト・フォーカスの見た目・文字サイズを決める → [[デザイントークン_05_運用(テーマ・アクセシビリティ・AI・チェックリスト)]]
- **見出しの構造**(h1 → h2 → h3)で情報を整理する
- リンクの文字は行き先がわかるように(「こちら」だけにしない)
- エラー・ローディング・空の状態の伝え方を決めておく
- アクセシブルな部品を共通化して、デザインシステムとして使い回す → [[デザインシステム]]
- 利用者の体験として考える → [[UXデザイン]]
