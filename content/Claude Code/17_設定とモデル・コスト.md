## 設定ファイル(settings.json)
| スコープ | ファイル | 影響範囲 | 使い道 |
| --- | --- | --- | --- |
| ユーザー | `~/.claude/settings.json` | 自分・全プロジェクト | テーマ、エディタ、既定モデル、個人の許可 |
| 共有プロジェクト | `.claude/settings.json` | チーム(gitにコミット) | チームの権限・Hooks・プラグイン・環境変数 |
| プロジェクトローカル | `.claude/settings.local.json` | 自分・このプロジェクト(git 除外) | 個人の上書き、共有前の試し |
| 管理(組織) | `managed-settings.json` / MDM / claude.ai コンソール | 組織全員 | セキュリティポリシー |

### 優先順位(上が強い)
1. 管理設定(誰も上書きできない)
2. コマンドライン引数
3. `.claude/settings.local.json`
4. `.claude/settings.json`
5. `~/.claude/settings.json`
- **リスト(`permissions.allow` など)は上書きでなくマージ**される
- 環境変数は別枠(キーごとに優先が決まる)

### 変更方法
- `/config`(設定画面)、`/config model=sonnet` のように直接
- `/update-config やりたいこと` … Claude が該当する settings.json を編集
- 手で編集してもOK。うまく効かない時は公式「Debug your configuration」
- `~/.claude.json` は Claude Code が自分で書くファイル(ログイン情報・MCP・プロジェクトごとの状態)。基本いじらない

### 設定例
```json
{
  "model": "sonnet",
  "permissions": {
    "defaultMode": "acceptEdits",
    "allow": ["Bash(npm run *)", "Bash(git status)"],
    "deny": ["Read(./.env)"]
  },
  "env": { "NODE_ENV": "development" },
  "hooks": { },
  "autoMemoryEnabled": true,
  "idleCompaction": true,
  "attribution": { }
}
```
- コミット・PR の署名(`Co-Authored-By` など)を消したいだけなら `"attribution": false`(v2.1.281〜)
- 広い端末で文章の幅を抑える: `maxProseWidth`

## モデル
### エイリアス
| エイリアス | 意味 |
| --- | --- |
| `opus` | 最新 Opus(Anthropic API では **Opus 5.5**)。**複雑な推論・設計**。全プランの既定 |
| `sonnet` | 最新 Sonnet(Anthropic API では **Sonnet 5.5**)。**日常のコーディング** |
| `haiku` | 速くて安い(Anthropic API では **Haiku 5.5**)。簡単な作業 |
| `fable` | Fable 5.1。**最難関・長時間のタスク** |
| `best` | 使えるなら fable、なければ opus |
| `opusplan` | プランモードは opus、実装は sonnet |
| `sonnet[1m]` `opus[1m]` | 100万トークンのコンテキスト(最新モデルは最初から 1M なので、今は旧モデル用) |
| `default` | アカウントの既定に戻す |
- 切替: `/model`、`claude --model opus`、設定 `"model"`、環境変数 `ANTHROPIC_MODEL`(新しいセッションの既定は `ANTHROPIC_DEFAULT_MODEL`)
- **既定モデル**: Pro / Max / Team / Enterprise / API すべて **Opus 5.5**(2026年9月22日から。Pro と Team Standard も Sonnet から Opus に変わった)。Fable はどのプランでも既定にはならない
- プロバイダで中身が違う: Bedrock・Google Cloud では `sonnet` = Sonnet 4.5、Microsoft Foundry の既定は Sonnet 4.5 など(公式 Model configuration の表を参照)
- 1M コンテキストが標準: Fable 5.x、Sonnet 5 以降、Haiku 5.5、Opus 4.7 以降

| モデル | 料金(入力/出力、100万トークンあたり) | 登場 |
| --- | --- | --- |
| Opus 5.5 | $4 / $20 | 2026-09-22 |
| Sonnet 5.5 | $2 / $10 | 2026-09-28 |
| Haiku 5.5 | $0.10 / $0.50(10万トークン超のプロンプトは $0.50 / $2.50) | 2026-10-07 |

- 流れ: 7月 Sonnet 5・Opus 5 → 9月 Fable 5.1・Opus 5.5・Sonnet 5.5 → 10月 Haiku 5.5

### Effort(思考の深さ)
- `low` `medium` `high` `xhigh` `max`(モデルによる)。低いほど速く安い
- `/effort high`、`--effort`、モデル選択画面で左右キー
- 既定: **Opus 5.5 / Sonnet 5.5 / Haiku 5.5 は `medium`**、Fable 5.x・Opus 5・Sonnet 5 は `high`、Opus 4.7 は `xhigh`
- 対応しない段階を指定すると、それ以下で最も高い段階になる(例: Opus 4.6 で `xhigh` → `high`)
- `ultracode` … 実質的なタスクごとにワークフローを組む最大モード。`/effort` の中で独立したトグル(`Tab`、または `/effort ultracode on|off`)

### その他
- **Fast モード**(`/fast`): Opus を最大2.5倍速く(料金は高い。サブスクでは追加クレジット扱い)。Opus 5.5 では研究プレビューの表記が外れた
- **Advisor**(`/advisor opus`): 重要な局面でより強いモデルに相談させる。`/advisor` か `advisorModel` 設定で選ぶまでは動かない
- **拡張思考**の ON/OFF: `Option+T`
- **自動コンパクションの閾値**: `/autocompact`

## 出力スタイル(Output styles)
応答の役割・口調・形式を変える。`/output-style 名前`
| スタイル | 変化 |
| --- | --- |
| Default | 標準 |
| Proactive | 細かい判断は聞かずに進める |
| Concise | 結論から、前置きなし |
| **Explanatory** | コードの選択理由を「Insight」で解説 → **学習中におすすめ** |
| **Learning** | 解説しつつ、小さな部分をあなたに書かせる → **手を動かして学びたい時** |
- 自作も可能(Markdown ファイル)。書き方は CLAUDE.md とは別物(CLAUDE.md = プロジェクトの事実、出力スタイル = 応答の仕方)

## インターフェース
- `/theme`(色覚対応テーマあり)、`/statusline`(下部にモデル・コンテキスト使用率などを表示。**コンテキスト量を常に見るのにおすすめ**)
- `/keybindings`、`/terminal-setup`(Shift+Enter で改行)
- `/tui fullscreen`(ちらつかない全画面描画)、`/focus`
- 音声入力 `/voice`、スクリーンリーダーモード

## コスト
- 課金は API トークン消費ベース。サブスク(Pro/Max 等)は定額の利用枠内
- 企業平均: 開発者1人あたり 約$13/稼働日、月$150〜250(90%のユーザーは1日$30未満)
- `/usage`(`/cost` `/stats`)でセッションのトークン・プラン上限・内訳を確認
- 上限に達したら: 自動で待って再開、追加クレジット(`/usage-credits`)、プランアップグレード。選択肢の一覧は `/rate-limit-options`
- `/usage` は「max effort」「ワークフロー」「常に読み込まれるコンテキスト」「大きなツール結果」など、枠を食う原因の警告も出す
- 長く放置した大きな会話を再開すると、キャッシュ切れで5時間枠の多くを使うことがある(Pro/Max は再開時に警告)

### トークン節約のコツ(公式)
- **タスク間で `/clear`**(前に `/rename` しておくと後で探せる)
- `/compact` に残す内容を指示、CLAUDE.md に「Compact instructions」
- **適切なモデル**: 大半は Sonnet、難しい設計だけ Opus、単純作業のサブエージェントは Haiku
- **MCP より CLI ツール**(`gh` `aws` など)。使わない MCP は無効化
- 型のある言語は**コードインテリジェンスプラグイン**
- 前処理は Hooks、手順は Skills に。CLAUDE.md の手順的な内容は Skills へ移す
- 冗長な作業(テスト実行、ログ解析)はサブエージェントへ
- 具体的なプロンプト、プランモード、早めの軌道修正、検証目標、少しずつテスト
