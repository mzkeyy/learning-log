## Claude Code とは
Anthropic が提供する**エージェント型のコーディングツール**。コードベース全体を読み、ファイルを編集し、コマンドを実行し、開発ツールと連携して、機能追加・バグ修正・自動化を行う。
チャットAIとの違いは「答えて終わり」ではなく、**自分で調べて・直して・テストして・確認するまで作業を続ける**こと。

できることの例(公式 Overview より):
- 後回しにしがちな作業の自動化(テスト追加、lint修正、マージコンフリクト解消、依存更新、リリースノート作成)
- 自然言語で機能追加・バグ修正(計画 → 複数ファイル編集 → 動作確認)
- コミット・PR作成
- MCP で外部サービス(Slack, Notion, DB など)と連携
- CLAUDE.md / Skills / Hooks でカスタマイズ
- CI(GitHub Actions 等)やスクリプトから実行

## 使える場所(サーフェス)
どこで使っても中身のエンジン(エージェントループ)は同じ。

| 場所 | 特徴 |
| --- | --- |
| **ターミナル(CLI)** | 全機能が使える基本形 |
| **VS Code / Cursor 拡張** | 差分表示、@メンション、プランのレビュー |
| **JetBrains プラグイン** | IntelliJ, PyCharm, WebStorm など(CLIが別途必要) |
| **デスクトップアプリ** | Claude アプリの「Code」タブ。複数セッションを並べる、差分を視覚的に確認、定期実行、クラウド起動。CLI不要(有料プラン) |
| **Web(claude.ai/code)** | ブラウザでクラウド上のClaudeを動かす。手元にないリポジトリも可 |
| **モバイル(iOS/Android)** | クラウドセッションや手元PCのセッションを操作 |
| **Slack / GitHub Actions / GitLab** | チャットやCIから呼び出す |

詳しくは [[16_利用環境(Desktop・IDE・Web・モバイル・ブラウザ)]]。

## 必要なもの
- Claude のサブスクリプション(**Pro / Max / Team / Enterprise**)、または Claude Console(API従量課金)アカウント
- もしくは Amazon Bedrock / Google Cloud / Microsoft Foundry 経由(企業向け)

## インストール(CLI)
```bash
# macOS / Linux / WSL(推奨: ネイティブインストール。自動更新される)
curl -fsSL https://claude.ai/install.sh | bash

# Homebrew(自動更新されない。brew upgrade が必要)
brew install --cask claude-code          # 安定版(約1週間遅れ、問題のある版をスキップ)
brew install --cask claude-code@latest   # 最新版
```
- Windows: PowerShell で `irm https://claude.ai/install.ps1 | iex`。Git for Windows を入れておくと Bash ツールが使える
- 確認: `claude --version`
- 見つからないと言われたら PATH の問題 → 公式「Troubleshoot installation」

## 起動とログイン
```bash
cd your-project
claude          # 初回はブラウザでログイン
```
- 環境変数 `ANTHROPIC_API_KEY` があるとログインを飛ばしてキーの承認を求める
- ログイン関連: `/login` `/logout`、`claude auth status`

## クイックスタートの流れ(公式 Quickstart)
1. インストール → 2. ログイン → 3. `claude` で起動
4. 質問してみる: 「このプロジェクトは何をするもの?」「フォルダ構成を説明して」
5. コードを変更させる: 「READMEにセットアップ手順を追加して」→ 変更前に承認を求められる
6. Git を使う: 「変更をコミットして」「feature ブランチを作って」
7. バグ修正・機能追加: 「ログインでエラーが出る原因を調べて直して」
8. 他のワークフロー: リファクタ、テスト作成、ドキュメント更新

## 初心者向けの心構え(公式 Pro tips)
- **完璧なプロンプトは不要**。会話しながら直していけばいい
- **委任する、細かく指示しすぎない**(「どのファイルを読め」まで言わなくても自分で探す)
- 困ったら Claude Code 自身に聞く(「hooks の設定方法は?」)。`/help`、`/powerup`(操作を学べるミニレッスン)
- `/init` で CLAUDE.md の雛形を作る、`/doctor` で環境診断

## 更新
- ネイティブ版はバックグラウンドで自動更新
- 手動: `claude update`、特定版: `claude install <version|stable|latest>`
- 変更点: `/release-notes`
