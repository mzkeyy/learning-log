Skills・サブエージェント・Hooks・MCP サーバー・LSP(言語サーバー)などを**1つにまとめてインストールできるパッケージ**。
- 単体の Skill や MCP は「自分だけ・1プロジェクト」なら十分。**複数リポジトリで同じ構成を使いたい / 人に配りたい**時にプラグインにする
- プラグインの Skill は名前空間付き: `/プラグイン名:スキル名`(他と衝突しない)
- **マーケットプレイス** = プラグインのカタログ。Anthropic 公式(`claude-plugins-official`)が最初から入っている

## 使う(インストール)
```text
/plugin                                              # Discover タブで探す
/plugin install commit-commands@claude-plugins-official   # 詳細画面を開き、スコープを選んで導入
```
- 詳細画面で「何が入るか」「コンテキストコスト(毎ターン/呼び出し時)」を確認できる
- **プラグインは Hook や MCP を実行できる**ので、入れる前に中身を確認
- 反映されない時は `/reload-plugins`
- シェルから: `claude plugin install ...` `claude plugin list`

### インストールスコープ
| スコープ | 有効範囲 |
| --- | --- |
| user | 自分の全プロジェクト(ターミナル・デスクトップ・VS Code 共通) |
| project | リポジトリの `.claude/settings.json` 経由でチーム全員(各自のPCでインストールは必要) |
| local | 自分・このリポジトリだけ |
※ クラウドセッションはローカル設定のプラグインを読まない

### マーケットプレイスを追加
```text
/plugin marketplace add owner/repo          # GitHub
/plugin marketplace add https://.../marketplace.json
/plugin marketplace add ./path/to/dir
```

## おすすめの公式プラグインの種類
- **コードインテリジェンス(LSP)**: TypeScript、Python など言語ごと。編集直後に型エラーを検知、定義・参照をシンボルで検索 → grep で大量に読むより正確で省コンテキスト(言語サーバー本体のインストールも必要。クラウドでは動かない)
- **security-guidance**: Claude が書いたコードを自動で自己セキュリティレビュー
- **Claude Security**: コードベース全体の脆弱性スキャン
- **commit-commands** などのワークフロー系
- **Channels**(Telegram / Discord / iMessage): 外部からセッションにメッセージを送る

## 作る
構成:
```text
my-plugin/
├── .claude-plugin/
│   └── plugin.json      # マニフェスト(名前・説明・バージョン)。ここには plugin.json だけ置く
├── skills/<name>/SKILL.md
├── agents/xxx.md
├── hooks/hooks.json
└── .mcp.json
```
- 開発中は `claude --plugin-dir ./my-plugin` でインストールせずに読み込んで試す
- `claude plugin eval` でテストケースを回し、プラグインなしと比較して効果を採点できる
- 配布: GitHub などに `marketplace.json` を置いてマーケットプレイスとして公開
- 既存の Skill フォルダに `.claude-plugin/plugin.json` を足すだけでプラグイン化もできる

## 組織向け
- 管理設定で許可するマーケットプレイス・プラグインを制限できる
- 組織におすすめプラグインを提示する仕組みもある
