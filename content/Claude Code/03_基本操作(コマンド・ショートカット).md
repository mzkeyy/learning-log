## 入力欄の記号
| 入力 | 意味 |
| --- | --- |
| `/` で始める | コマンドやスキルを実行 |
| `!` で始める | シェルモード。コマンドを直接実行し、その出力を会話に入れて Claude に反応させる |
| `@` | ファイルパスの補完・参照(`@src/app.ts` で中身を読ませる)。サブエージェント指名にも使う |
| `?`(空欄で) | ショートカット一覧 |
| 画像を貼る | `Ctrl+V`(iTerm2 は `Cmd+V`)、ドラッグ&ドロップ |

## 主要なキーボードショートカット
| キー | 動作 |
| --- | --- |
| `Esc` | Claude を即停止(会話は保持) |
| `Esc` `Esc` | 入力の下書きを消す / 巻き戻しメニュー(`/rewind`) |
| `Shift+Tab` | 権限モードの切替(Manual → Accept edits → Plan → Auto …) |
| `Ctrl+C` | 中断・入力クリア |
| `Ctrl+D` | 終了 |
| `Ctrl+G` | 入力やプランを外部エディタで開く |
| `Ctrl+O` | トランスクリプト(詳細ログ)表示 |
| `Ctrl+R` | 入力履歴の検索 |
| `Ctrl+B` | 実行中のタスクをバックグラウンドへ |
| `Ctrl+T` | タスクチェックリスト表示 |
| `Ctrl+S` | 入力の一時退避/復元 |
| `Ctrl+Enter`(または `Ctrl+X` `Ctrl+S`) | **今すぐ送信**: 作業中でもキューの指示をまとめて送る(実行中のツールはバックグラウンドへ移る) |
| `Option+P` / `Alt+P` | モデル切替 |
| `Option+T` / `Alt+T` | 拡張思考のON/OFF |
| `Option+O` / `Alt+O` | Fast モード切替 |
| `↑` `↓` | 履歴 |
- 改行: `Shift+Enter`(端末によっては `/terminal-setup` で設定)。macOS の Option キー系は端末で「Option を Meta として使う」設定が必要
- キー割り当て変更: `/keybindings`

## よく使うコマンド(場面別)
### 初めてのリポジトリで
- `/init` … CLAUDE.md の雛形を生成(既にあれば改善案)
- `/memory` … CLAUDE.md・自動メモリの編集
- `/mcp` … MCP サーバーの接続・認証
- `/permissions` … 許可/拒否ルールの管理
- `/doctor` … 環境チェックと修正提案(`/checkup`)

### 作業中
- `/plan [説明]` … プランモードに入る
- `/model` … モデル切替(`s` でこのセッションだけ)
- `/effort` … 推論の深さ(low〜max)。Ultracode は別トグル(`/effort ultracode on|off`)
- `/context` … コンテキスト使用状況
- `/compact [指示]` … 会話を要約して空きを作る
- `/btw 質問` … 会話履歴に残さない脇道の質問
- `/diff` … 変更差分を確認
- `/tasks` … バックグラウンド作業一覧
- `/goal 条件` … 条件を満たすまで作業を続けさせる
- `/loop 5m 指示` … 一定間隔で繰り返し実行

### 出荷前
- `/code-review` … 差分のバグチェック(`--fix` で修正適用、`--comment` で PR にコメント、`--max-findings 数|all` で件数、`ultra` でクラウドの多重レビュー)。別名 `/review`
- `/simplify` … 重複・複雑さ・効率の改善(バグ探しはしない)
- `/security-review` … セキュリティ観点の差分チェック
- `/verify` `/run` … 実際にアプリを起動して動作確認

### セッションの切替
- `/clear` … 新しい会話を始める(別名 `/new` `/reset`)
- `/resume` … 過去の会話に戻る
- `/rename 名前` … セッションに名前を付ける
- `/branch` … 会話を分岐して別の方向を試す
- `/fork` … 会話をコピーしてバックグラウンドで別作業
- `/subtask 作業` … 会話を引き継いだサブエージェントに脇作業を任せる
- `/rewind` … チェックポイントへ巻き戻し(別名 `/undo`)
- `/export` … 会話をテキストで書き出し

### 困ったとき
- `/doctor` … インストール・設定の診断
- `/debug` … デバッグログを取って原因調査
- `/bug`(別名 `/share`) … 不具合報告・会話の共有。`/feedback` … フィードバック(Claude が下書きしたレポートを確認して送れる)
- `/help` … ヘルプ、`/powerup` … 機能を学ぶミニレッスン

### その他の便利コマンド
- `/usage` … 利用量・プランの上限(`/cost` `/stats`)。上限に達した時の選択肢は `/rate-limit-options`
- `/config` … 設定画面(テーマ・モデル・出力スタイルなど)。`/config theme=dark` のように直接指定も可
- `/theme` `/statusline` `/output-style` `/fast`(Vim モードは `/vim` が廃止され `/config` → Editor mode)
- `/skills` `/plugin` `/hooks` `/agents`(サブエージェントは今は Claude に頼んで作る)
- `/add-dir` … 作業ディレクトリを追加、`/cd` … セッションを別ディレクトリへ移動
- `/desktop` … デスクトップアプリで続ける、`/remote-control` … スマホ等から操作、`/teleport` … クラウドのセッションを手元へ
- `/schedule` … クラウドで定期実行(Scheduled tasks。旧 routines。別名 `/routines`)
- `/auto-mode-setup` … プロジェクトと最近のセッションを読んで、Auto モードに自分の環境(使うドメインやツール)を教えるガイド付き設定
- `/insights` … 自分の使い方の分析レポート
- `/import` … Codex / Gemini CLI / Cursor の設定を取り込む
- `/batch 指示` … 大規模変更を5〜30個に分割して並列実行
- `/deep-research 質問` … 多数のWeb検索で出典付きレポート
- `/design` … UIモックをアートボードで作る(アーティファクト機能)

> コマンドはメッセージの**先頭**でのみ認識される。スキルは `/skill-a /skill-b 引数` のように最大6個まで連結可能。
> 廃止済み: `/ultraplan`(→ プランモード)、`/pr-comments`(→ Claude に直接頼む)、`/vim`(→ `/config`)

## CLI(起動時)の主なコマンド・オプション
```bash
claude                      # 対話モード
claude "質問"               # 最初の質問付きで起動
claude -p "質問"            # 非対話(結果を出力して終了)
claude -c                   # このフォルダの直近の会話を再開
claude -r "名前"            # 名前/IDで再開
claude --permission-mode plan   # プランモードで起動
claude --model opus         # モデル指定
claude -w feature-x         # git worktree を作ってその中で起動
claude --add-dir ../shared  # 追加ディレクトリ
claude agents               # エージェントビュー(バックグラウンドセッション一覧)
claude --desktop            # このフォルダ(やセッション)をデスクトップアプリで開く
claude mcp add ...          # MCP追加
claude plugin ...           # プラグイン管理
claude doctor               # 診断(セッションを開かない)
claude purge [path]         # プロジェクトのローカル状態を削除(旧 claude project purge)
claude update               # 更新
```
その他: `--allowedTools` `--disallowedTools` `--append-system-prompt` `--output-format json` `--bare`(拡張を読み込まない最小モード) `--debug` `--chrome` `--cloud` `--bg`(バックグラウンド起動) `--safe-mode`(カスタマイズを全部切って起動。トラブル調査用)など。
