modified: 2026-10-18

**色・余白・文字サイズ・角丸などデザインの決まりごとに名前を付け、1か所で管理する変数**。「`#ff5500`」と直接書く代わりに「`primary`」と書くイメージ。デザイナー・エンジニア・AI が同じ言葉で話せるようになり、変更は1か所で全体に反映される。

W3C Design Tokens Community Group の仕様(**2025.10 安定版**)、Style Dictionary、shadcn/ui・Tailwind CSS の公式ドキュメントを元に整理したノート群の入口(2026年9月時点)。

## 全体の流れ
```
[決める]  デザイナー / チーム(Figma Variables など)
    │  JSON(W3C DTCG 形式 .tokens.json)
    ▼
[変換]    Style Dictionary など
    │
    ├─▶ Web: CSS 変数(:root / .dark)→ Tailwind(@theme)→ shadcn/ui の bg-primary など
    ├─▶ iOS: Swift
    └─▶ Android: XML / Compose
[使う]    コンポーネントは「役割の名前」だけを参照(値を直書きしない)
```

## なぜ必要か(要点)
- 直書きだとブランドカラー変更で全ファイルを探して直すことになる → 名前で管理すれば1か所で済む
- **AI は放っておくと毎回微妙に違う色・余白を使う** → トークンで縛ると出力が安定する
- 画面を作る時は「黄色」ではなく「主要アクション(primary)」と**役割で**考える
