## IDE と ADE
| 観点 | IDE(VS Code など) | ADE(Orca) |
| --- | --- | --- |
| 主役 | 人がコードを書く | **AI が書き、人が指示・確認する** |
| 作業単位 | 1行ずつの編集 | 1つの課題(タスク)全体 |
| 同時進行 | 基本1つ | **複数を並行** |
| 画面の中心 | ファイルとカーソル | 作業一覧とエージェントのログ |

## 仕組み: git worktree で並列にする
- 複数のエージェントを同じフォルダで動かすと、同じファイルを取り合って壊れる
- **git worktree** = 1つのリポジトリから、ブランチごとに**別の作業フォルダ**を作る Git の機能
- Orca は「1タスク = 1ワークツリー = 1ブランチ」で、各エージェントを別フォルダで動かす → 互いに干渉しない
- 各リポジトリには起点(base ref、通常 `origin/main`)があり、そこから枝分かれする
- 同じ指示を複数エージェント(例: Claude Code と Codex)に投げ、**結果を比べて良い方を採用**することもできる

## 主な機能(公式)
| 機能 | 内容 |
| --- | --- |
| 並列ワークツリー | タスクごとの隔離された作業場所。GitHub・Linear・Jira の課題から直接作成 |
| 分割ターミナル | 高速描画・無制限分割・再起動後も履歴保持 |
| エディタ | VS Code 互換、ファイル/画像のドラッグでエージェントに渡せる |
| 差分レビュー | 差分の行ごとにコメント(AI Diff アノテーション)→ エージェントに差し戻し。コミット・push・PR・CI 待ちまでアプリ内で |
| 内蔵ブラウザ・Design Mode | ワークツリーごとの Chromium。UI 要素をクリックすると HTML・CSS・スクショがエージェントへ |
| SSH ワークツリー | 別マシンでエージェントを実行 |
| モバイルアプリ | iPhone / Android から監視・返答・通知 |
| Orca CLI | ワークツリー作成やブラウザ操作をコマンドで |
| アカウント切替・使用量表示 | Claude・Codex の複数契約と利用量を管理 |
| その他 | Quick Open、Markdown・画像・PDF プレビュー、Computer Use、通知・未読管理 |

## 対応エージェント
**CLI で動くものならほぼ何でも**: Claude Code、Codex、Gemini、Grok、Cursor CLI、GitHub Copilot、OpenCode、Cline、Devin、Amp、Kiro、Qwen Code など数十種類。自分の契約(サブスク)をそのまま使う。

## 費用
- Orca 本体: **無料**(MIT ライセンス)
- エージェント: 既存の契約・API 料金。**同時に動かした数だけ消費**
- SSH 先やクラウド VM を使うならその費用
- 企業向けの価格は非公開(問い合わせ)

## 向いている人・向かない人
| 向いている | 不要 |
| --- | --- |
| エージェントを2体以上同時に動かしたい | 1体で足りている |
| 複数の案を比較して選びたい | 特定エージェントの手順に固定されている |
| worktree の手作業管理が面倒 | Git を日常的に使わない |

## 注意点
- 更新が非常に速く、画面・機能がよく変わる(小さな会社のプロダクト)
- 並列にするほど**確認する差分と費用が増える** → 人間のレビューが追いつく数にとどめる
- 権限設計が重要([[Orca_02_導入と初期設定]])
- テレメトリ(利用状況の送信)は設定で確認・無効化できる

## Claude Code 単体との比較
| | Claude Code 単体 | Orca |
| --- | --- | --- |
| 並列 | worktree・サブエージェント・エージェントビュー([[14_並列作業(Worktree・Agent View・Workflows)]]) | 複数の**異なる**エージェントをまとめて管理 |
| 画面 | ターミナル / デスクトップアプリ | 専用の統合画面(ターミナル・エディタ・差分・ブラウザ) |
| エージェント | Claude のみ | Claude・Codex・Gemini などを混在 |
