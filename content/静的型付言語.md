---
title: "静的型付言語"
modified: 2026-10-18
---

変数や関数の型などをプログラムの**実行前(コンパイル時)にチェック**する言語。例: TypeScript、Java、Go、Rust、C#。
(コンパイル = 人が書いたコードを、実行できる形(機械語や別の言語)に変換すること)

| | 静的型付け | 動的型付け |
| --- | --- | --- |
| 型の確認 | 実行前(コンパイル時) | 実行中 |
| 例 | TypeScript, Java, Go, Rust | JavaScript, Python, Ruby |
| 利点 | 間違いを早く見つける・補完が効く・リファクタリングが安全 | 書き始めが手軽 |

- **TypeScript** は動的型付けの JavaScript に静的な型チェックを足したもの。型はチェック後に取り除かれ、JavaScript として実行される(機械語にはしない)
- 詳しくは → 📚 [[TypeScript]]
